# LOCAL SIMULATION - a local bare repo stands in for GitHub (origin)

## 01. Check Git and set identity
$ cd ~/git-lab
$ git --version
git version 2.43.0
$ git config --global user.name "Susan"
$ git config --global user.email "susan@example.com"
$ git config --global --list
init.defaultbranch=main
color.ui=false
advice.detachedhead=false
user.name=Susan
user.email=susan@example.com

## 02. Create the local project
$ cd ~/git-lab
$ mkdir hello-github
$ cd ~/git-lab/hello-github
$ git init
Initialized empty Git repository in ~/git-lab/hello-github/.git/
$ ls -a
.
..
.git

## 03. Create README.md and check status
$ cd ~/git-lab/hello-github
$ cat README.md
# Hello GitHub

My first repository, created for the Git/GitHub lab (Experiment 25).

## About
This repository shows how to create a project locally, connect it to a
remote repository on GitHub and push a README file.

## Author
- **Name:** Ashira Bridget Susan S
- **Programme:** B.Tech AI & Data Science, SIMATS Engineering

## Commands used
```bash
git init
git add README.md
git commit -m "Add README"
git remote add origin <repository-url>
git push -u origin main
```
$ git status

## 04. Stage and commit
$ cd ~/git-lab/hello-github
$ git add README.md .gitignore
$ git status
On branch main

No commits yet

Changes to be committed:
  (use "git rm --cached <file>..." to unstage)
	new file:   .gitignore
	new file:   README.md
$ git commit -m "Add README and .gitignore"
[main (root-commit) b70100f] Add README and .gitignore
 2 files changed, 24 insertions(+)
 create mode 100644 .gitignore
 create mode 100644 README.md
$ git log --oneline
b70100f Add README and .gitignore

## 05. Connect the remote and push
$ cd ~/git-lab/hello-github
$ git remote add origin <repository-url>
$ git remote -v
origin	~/git-lab/remote/hello-github.git (fetch)
origin	~/git-lab/remote/hello-github.git (push)
$ git branch -M main
$ git push -u origin main
branch 'main' set up to track 'origin/main'.
To ~/git-lab/remote/hello-github.git
 * [new branch]      main -> main
$ git status
On branch main
Your branch is up to date with 'origin/main'.

nothing to commit, working tree clean
