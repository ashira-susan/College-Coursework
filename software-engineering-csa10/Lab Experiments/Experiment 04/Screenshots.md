# Experiment 04: Scrum Project Management using Jira

## Aim
To create a Scrum Project in Jira Software, build and prioritize a project backlog with at least 5 work items, configure a 1-week sprint, move items into the active sprint, track task progression across the Sprint Board, and complete the sprint.

---

## Tool Used
- **Software:** Atlassian Jira Software (Cloud Edition)
- **Project Type:** Scrum

---

## Procedure & Steps Executed

### Step 1: Create a Scrum Project
1. Log in to Jira Software.
2. Click on **Spaces / Projects** and select **Create project**.
3. Select the **Scrum** project template.
4. Set the project name as `Scrum Experiment` (Key: `SE`).

### Step 2: Add Backlog Items
Navigate to the **Backlog** section from the left sidebar and create 5 work items:
1. `SE-1`: Create user registration page
2. `SE-2`: Develop API for login
3. `SE-3`: Design database schema
4. `SE-4`: Implement password reset feature
5. `SE-5`: Setup CI/CD deployment pipeline

### Step 3: Prioritize Backlog and Configure Sprint
1. Arrange the backlog items in order of execution priority from top to bottom.
2. Click **Create sprint** to generate a new sprint container (`SE Sprint 1`).
3. Drag all 5 prioritized work items from the Backlog into `SE Sprint 1`.
4. Click **Edit sprint** and set the duration to **1 week**.

### Step 4: Start and Execute the Sprint
1. Click **Start sprint** to activate the sprint board.
2. Track work progression by moving issues across status columns (**To Do**, **In Progress**, and **Done**) as development progresses.

### Step 5: Complete the Sprint
1. Click **Complete sprint** once the sprint cycle concludes.
2. Review completed items (`SE-1` and `SE-2`) vs open remaining items (`SE-3`, `SE-4`, and `SE-5`).
3. Move the remaining open items into a subsequent sprint (`SE Sprint 2`).
