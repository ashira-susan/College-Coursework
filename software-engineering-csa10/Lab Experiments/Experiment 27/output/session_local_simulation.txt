# LOCAL SIMULATION - a local bare repo stands in for GitHub (origin)

## 01. (setup) clone the project

## 02. First change: add a file
$ cd ~/git-lab/commit-demo
$ git status
On branch main
Your branch is up to date with 'origin/main'.

Untracked files:
  (use "git add <file>..." to include in what will be committed)
	calculator.py

nothing added to commit but untracked files present (use "git add" to track)
$ git add calculator.py
$ git diff --staged
diff --git a/calculator.py b/calculator.py
new file mode 100644
index 0000000..0dd0baf
--- /dev/null
+++ b/calculator.py
@@ -0,0 +1,6 @@
+def add(a, b):
+    return a + b
+
+
+if __name__ == "__main__":
+    print(add(2, 3))
$ git commit -m "Add calculator with add()"
[main e9a10dd] Add calculator with add()
 1 file changed, 6 insertions(+)
 create mode 100644 calculator.py

## 03. Second change: modify the file
$ cd ~/git-lab/commit-demo
$ git diff

+    return a - b
+
+
 if __name__ == "__main__":
     print(add(2, 3))

## 04. Ignore files and add documentation
$ cd ~/git-lab/commit-demo
$ echo '*.log' > .gitignore   # ignore log files
$ git status -s
?? .gitignore
?? README.md
$ git add README.md .gitignore
$ git commit -m "Add README and .gitignore"
[main dd19072] Add README and .gitignore
 2 files changed, 6 insertions(+)
 create mode 100644 .gitignore
 create mode 100644 README.md
