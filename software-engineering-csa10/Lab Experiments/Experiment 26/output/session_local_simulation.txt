# LOCAL SIMULATION - a local bare repo stands in for GitHub (origin)

## 01. (setup) a repository already exists on 'GitHub'

## 02. Clone the repository
$ cd ~/git-lab
$ git clone <repository-url>
Cloning into 'student-notes'...
done.
$ cd ~/git-lab/student-notes
$ ls -a
.
..
.git
README.md
notes.md
$ git remote -v
origin	~/git-lab/remote/student-notes.git (fetch)
origin	~/git-lab/remote/student-notes.git (push)
$ git log --oneline
f856bc0 Initial notes

## 03. Edit existing file and add a new file
$ cd ~/git-lab/student-notes
$ cat notes.md
# Notes

- Git tracks changes to files.
- GitHub hosts repositories online.
$ echo "...new lines..." >> notes.md   # or edit in VS Code
$ ls
README.md
notes.md
todo.txt

## 05. Stage, commit and push

$ git add notes.md todo.txt
$ git commit -m "Update notes and add todo list"

$ git push origin main
