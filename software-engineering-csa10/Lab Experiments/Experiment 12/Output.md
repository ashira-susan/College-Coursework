# 💻 Software Engineering Lab - Experiment 12

* **Course:** CSA10 – Software Engineering Laboratory Manual
* **Institution:** Saveetha School of Engineering | SIMATS
* **Project:** Task Management System (TMS)

---

## 🎯 Objective
To implement a Scrum project setup in Jira, manage project requirements through a sprint backlog, and prioritize tasks using both the **MoSCoW** and **Kano** prioritization models.

---

## 📊 Requirement Prioritization Matrix

| Task ID | Requirement Name | MoSCoW Priority | Kano Category |
| :--- | :--- | :--- | :--- |
| **TMS-1** 🔐 | User Login and Role Assignment | Must Have | Basic |
| **TMS-2** 📝 | Task Creation and Assignment | Must Have | Basic |
| **TMS-3** ⏱️ | Task Prioritization and Deadlines | Should Have | Performance |
| **TMS-4** 📈 | Progress Tracking and Reporting | Could Have | Excitement |
